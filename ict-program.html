Welcome to the ICT Program

About the Program

The ICT (Information and Communication Technology) program is designed to equip students with the necessary skills and knowledge in the field of information and communication technology.

Students will develop their digital skills through theory and practical activities.

Learning Topics

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL

Learning Roadmap

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript
  4. Learn PHP
  5. Learn MySQL

Technology Definitions

HTML
HTML is used to structure content on a webpage.
CSS
CSS is used to style a webpage.
JavaScript
JavaScript is used to make webpages interactive.
